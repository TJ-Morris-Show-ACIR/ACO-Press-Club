# Reality-Layer Labeling System

**Status:** Public editorial standard  
**Connected draft:** SOLON Working Draft — May 2026

This system keeps public writing clean by separating fact, memory, symbol, speculation, and story.

| Layer | Meaning | Public treatment |
|---|---|---|
| Established fact | Publicly documented, source-checkable material | State clearly with source in final publication |
| User firsthand memory | TJ Morris lived memory or direct recollection | Use language such as “TJ Morris recalls…” |
| Community / oral history | Shared memory not yet independently documented | Use “in community memory…” or “oral-history account…” |
| Speculative research | Possible connection still under review | Use “a research question remains…” |
| Symbolic / canon language | ACIR, Vivarium, Aeonic Codex, spiritual, teaching, or project-mythic language | Label as symbolic, canon, teaching, or project framework |
| Fiction / worldbuilding | Story-world, novel, script, mythology, or creative expansion | Label clearly as fiction or story-world |

## Rule

Do not flatten the archive. Preserve the versions, label them correctly, and protect the witness.

## Working principle

Build the record. Protect the witness. Separate fact, memory, symbol, speculation, and story. Harm none.
