# Merge Protocol for Original DOCX

**Original target file:** `UFO_Association_Guide_Book_TJ_Edit.docx`  
**Current public working edition:** `SOLON_Working_Draft_May_2026.md`

## Editorial boundary

The SOLON Working Draft is not the recovered original DOCX. It is a public working edition built from the May 24, 2026 SOLON gathering and UFO/UAP notes.

When the original DOCX is located or uploaded, do not overwrite the SOLON draft.

## Required preservation layers

### Layer A — Original DOCX Text

Preserve exactly as found, including older language where appropriate.

### Layer B — SOLON Working Draft May 2026

Preserve the current public working edition as a dated reconstruction and expansion.

### Layer C — Public Edited Edition

Create a clean reader-facing version that blends the best of both while labeling older, newer, symbolic, and research-only material.

## Recommended filenames

- `UFO_Association_Guide_Book_original_DOCX_preserved.docx`
- `SOLON_Working_Draft_May_2026.md`
- `UFO_Association_UAP_Associates_Public_Edition_v1.md`
- `UFO_Association_UAP_Associates_Public_Edition_v1.pdf`

## Passage labels

Each merged passage should be marked as one of:

- Original DOCX wording
- May 24 SOLON working addition
- Later editorial addition
- Public-facing rewrite
- Research note only

## Rule

Merge without erasing either version.
